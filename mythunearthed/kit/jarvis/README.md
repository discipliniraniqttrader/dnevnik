# Джарвис 👏👏

Плясни два пъти → Джарвис те поздравява, отваря работното ти място и слуша гласови команди.

## Инсталация (5 минути)
1. Инсталирай **Python 3.10+** от python.org. На Windows отметни **"Add Python to PATH"**.
2. Отвори терминал в тази папка и изпълни:
   ```
   pip install -r requirements.txt
   ```
   На macOS преди това: `brew install portaudio`. На Linux: `sudo apt install libportaudio2 espeak`.
3. Стартирай:
   - Windows: двоен клик на `start_windows.bat`
   - macOS / Linux: `./start_mac_linux.sh`

## Прозорецът (виждаш дали те чува)
При стартиране се отваря страница в браузъра: **http://127.0.0.1:8765**
- **Кръгът и лентата** мърдат, когато микрофонът те чува. Цветът показва състоянието: сиво = чака, синьо = слуша, жълто = изпълнява, зелено = успех, червено = неуспех.
- **„Какво се случва“**: всичко, което е чул, какво е отговорил и дали командата е изпълнена (✓ / ✗).
- **Поле за писане**: можеш да даваш команди и с клавиатурата, без „Джарвис“ и „край“.
- **Пауза** спира микрофона.
- `python jarvis.py --console` работи без прозорец, `python jarvis.py --demo` показва прозореца без микрофон.

## Как се говори с него
Всяка команда започва с **„Джарвис“** и завършва с **„край“**:

> „Джарвис, пусни в YouTube лофи музика, край“

Може и на части: „Джарвис“ … (пауза) … „търси рецепта за мусака“ … „край“.
Без „Джарвис“ отначало нищо не се изпълнява. Ако „край“ не дойде до 20 секунди, командата се отменя.
**Двойно пляскане** пуска сутрешната рутина.

## Команди (по подразбиране)
| Кажи „Джарвис … край“ с | Какво става |
|---|---|
| изключи компютъра | изключва след 30 s |
| рестартирай | рестарт след 30 s |
| отмени | спира изключването/рестарта (Windows, Linux) |
| заспивай | режим на сън |
| заключи | заключва екрана |
| добро утро | сутрешната рутина |
| колко е часът / коя дата сме | казва часа или датата |
| търси … | търсене в Google |
| пусни в YouTube … | търсене в YouTube |
| отвори пощата / календара / калкулатора | отваря ги |
| какво е времето | прогнозата |

## Режими
| Команда | Какво прави |
|---|---|
| `python jarvis.py` | пляскане + гласови команди |
| `python jarvis.py --no-clap` | само гласови команди |
| `python jarvis.py --run` | пуска рутината веднага |
| `python jarvis.py --mic-test` | показва нивата на микрофона |

## Настройка — всичко е в `config.json`
- `your_name` — как да те нарича.
- `wake_words` / `end_words` — думите за начало и край (може да ги смениш, напр. „Фрайдей“ и „готово“).
- `routine` — какво става при двойно пляскане. Типове действия:
  - `say` — казва текст (`{name}`, `{time}`, `{date}` се заместват)
  - `open_url` — отваря сайт
  - `open_app` — отваря програма (Windows: `notepad`, `calc` или пълен път до .exe; macOS: име на приложение, напр. `Spotify`)
  - `system` — `shutdown`, `restart`, `cancel`, `sleep`, `lock`
  - `shell` — изпълнява команда
  - `wait` — пауза в секунди
- `commands` — нови гласови команди: `phrases` (какво казваш) + `actions`. `{query}` в адрес = това, което кажеш след фразата.

## Не реагира на пляскане / реагира на всичко
Пусни `--mic-test` и пляскай. Пиковете на пляскане трябва да са над `clap.min_level` (0.12).
- Не хваща → намали `min_level` (напр. 0.06) или `sensitivity` (напр. 4).
- Хваща случайни звуци → увеличи ги.

## Да тръгва сам с компютъра
- **Windows:** `Win+R` → `shell:startup` → сложи там пряк път към `start_windows.bat`.
- **macOS:** System Settings → General → Login Items → добави `start_mac_linux.sh`.

## Важно
- Компютърът трябва да е **включен** (може със заключен екран). Изключен или заспал компютър не чува микрофона, затова Джарвис може да го изключи, но не и да го включи.
- Разпознаването на реч ползва безплатната услуга на Google, затова трябва интернет. Пляскането работи и без интернет.
- Български глас: на Windows добави българския езиков пакет с „Speech“ (Settings → Time & Language → Language), после в `config.json` сложи `"voice_name": "Ivan"`. Без него Джарвис говори с английския глас по подразбиране или само пише.
